## HDRP Wizard Setup

After cloning the project and opening it in Unity, you may see the **HDRP Wizard** window. This wizard helps you configure the High Definition Render Pipeline (HDRP) settings for your project.

**What to do:**
- Review the configuration checks in the wizard.
- If you see any warnings or errors, follow the wizard's recommendations to fix them.
- If prompted, click the buttons to migrate or upgrade materials and settings as needed.
- Make sure all checkmarks are green for best compatibility.

**Note:**  
If your project contains custom or non-built-in materials, the wizard may skip them during migration. You may need to manually update those materials to be compatible with HDRP.

You can always reopen the HDRP Wizard from the Unity menu:  
`Window > Rendering > HDRP Wizard`
